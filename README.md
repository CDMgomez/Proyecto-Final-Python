# Proyecto Final Django – Sandwichería

Este proyecto fue desarrollado como **proyecto final** utilizando el framework **Django**.

La aplicación representa una **sandwichería**, con el objetivo de simular un sistema real de gestión de productos y usuarios, integrando funcionalidades de backend, autenticación y manejo de datos.

---

## 🚀 Funcionalidades principales

- Página principal (Home)
- Listado de productos / menú
- Detalle individual de cada producto
- CRUD de páginas (crear, editar y eliminar productos)
- Sistema de registro, login y logout
- Perfil de usuario
- Edición de perfil (avatar y biografía)
- Mensajería interna entre usuarios
- Sección **About** explicando el objetivo del proyecto

---

## 👤 Usuarios y autenticación

- Los usuarios pueden registrarse y acceder a su cuenta
- El acceso a funciones sensibles está protegido por autenticación
- Cada usuario cuenta con un perfil editable

---

## 💬 Mensajería

La aplicación incluye un sistema básico de mensajería interna que permite el envío de mensajes entre usuarios registrados.

---

## ℹ️ About – Objetivo del proyecto

Este proyecto surge a partir del interés por desarrollar una aplicación web que permita gestionar datos, productos y usuarios de forma organizada.

El objetivo a largo plazo es poder aplicar conceptos de **análisis de datos** en un negocio propio, especialmente dentro del rubro gastronómico, un área que resulta de gran interés para el autor.

Por este motivo, el desarrollo de esta aplicación se encuentra alineado con la formación en **Analista de Datos**, buscando integrar tecnología, datos y negocio.
